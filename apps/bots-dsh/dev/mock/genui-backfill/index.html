The interactive backfill card

A Bot proposes reading a chat's history. The person ticks the chats and sets the dates, then presses Start once: that single approval starts one backfill per chat. The runs move live beside it, and a chat that is still running can be stopped. Everything here is sample data, and this page calls nothing.
